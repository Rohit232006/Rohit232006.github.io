The Challenge

Dense, legacy interfaces that slow down daily pharmacy tasks

Existing pharmacy POS tools had cluttered interfaces with poor visual hierarchy — staff had to navigate multiple tools for a single prescription workflow.

The Approach

Density with clarity — efficient without being overwhelming

Designed a role-based SaaS dashboard where the most frequent tasks (patient search, prescription status, refill) are surfaced within two clicks.

The Outcome

9 hi-fi screens · Full design system · Presentation deck

A complete, handoff-ready Figma file with documented components, tokens, annotated flows and a full case study presentation deck.

"Dense doesn't have to mean cluttered.
The interface needed density with clarity — not simplification."

Design Principle · PharmaFlow

Process
01

How I approached it

Solo case study — full UX and UI pipeline from research through pixel-precise Figma deliverables.

✓

Discovery & Competitive Benchmarking Done

Audited existing pharmacy POS tools to identify UX gaps — most had cluttered, legacy interfaces with poor visual hierarchy. Mapped core task flows staff repeat daily to determine primary vs. secondary actions.

✓

Information Architecture Done

Defined a clear IA: Dashboard overview → Patient Search → Patient Profile → Prescription Detail → Refill flow. Organised sidebar navigation around frequency-of-use, not features.

✓

Wireframing & Layout Exploration Done

Low-fidelity wireframes for 9 core screens. Tested multiple layout patterns for the patient profile and settled on a two-column layout with sticky sidebar summary and scrollable prescription timeline.

✓

Design System & Colour Tokens Done

Built a custom design system in Figma with a warm dark-mode palette, semantic colour tokens for status states (active, pending, flagged, expired) and a component library covering tables, cards, inputs and modals.

✓

Hi-Fi Screens & Presentation Deck Done

Polished all screens to pixel-precise Figma fidelity and assembled a full presentation deck documenting design decisions, component specs and information hierarchy rationale.
