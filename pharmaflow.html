The problem and the brief

PharmaFlow was designed as a SaaS point-of-sale and prescription management system for independent pharmacies. Pharmacy staff needed a single dashboard to manage patient profiles, track active prescriptions, process refills and view prescription history without switching between multiple tools or paper records.

The core challenge was designing a dense, information-rich interface that remained scannable and efficient for high-frequency daily tasks, while keeping the visual language clean enough for staff who aren't technically trained.

// process

How I approached it

01

Discovery and Competitive Benchmarking

Audited existing pharmacy POS tools to identify UX gaps. Most had cluttered, legacy interfaces with poor visual hierarchy. Mapped core task flows staff repeat daily to determine primary vs. secondary actions.

02

Information Architecture

Defined a clear IA: Dashboard overview to Patient Search to Patient Profile to Prescription Detail to Refill flow. Organised the sidebar navigation around frequency-of-use, not features.

03

Wireframing and Layout Exploration

Created low-fidelity wireframes for 9 core screens. Tested multiple layout patterns for the patient profile and settled on a two-column layout with sticky sidebar summary and scrollable prescription timeline.

04

Design System and Colour Tokens

Built a custom design system in Figma with a warm dark-mode palette, semantic colour tokens for status states (active, pending, flagged, expired) and a component library covering tables, cards, inputs and modals.

05

High-Fidelity Screens and Presentation

Polished all screens to pixel-precise Figma fidelity and assembled a full presentation deck documenting design decisions, component specs and information hierarchy rationale.
